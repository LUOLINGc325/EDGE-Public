# Persistent memory is required to observe schedule-induced indivisibility

**量子通道可分性缺陷的检测与记忆下界**

Whenever a schedule of channel choices can produce a positive postprocessing defect at a given time, a detector with one classical bit can witness positivity at that time. The detector library may depend on the target time. An explicit schedule shows that witnessing a fixed fraction of the unrestricted defect can require a number of persistent qubits proportional to the history length.

若给定的通道选择序列能在某个时刻产生正的后处理缺陷，则选择针对该时刻的信道库后，一个经典比特即可检出正缺陷。论文也给出显式序列，证明检出无限制缺陷的固定比例时，所需持久量子比特数可以与历史长度成正比。

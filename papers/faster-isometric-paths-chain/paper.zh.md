# 链图等距路径划分与覆盖的更快算法

## 摘要

Chakraborty 等人给出链图的等距路径划分及覆盖算法，并提出改进时间界。本文使用五个路径族计数表示其正规形，利用链邻接的排序匹配性质对齐四顶点路径。预处理固定步长的邻接查询后，每个正规形可在常数时间验证。划分与覆盖的时间分别由 $O(n^7)$、$O(n^9)$ 降为 $O(n^5)$、$O(n^7)$，均输出最优见证。

## 1. 问题

等距路径是两端点间的最短路径，可以只含一个顶点。覆盖允许路径重叠，划分要求路径顶点互不重叠，二者都要求覆盖全图。链图的边连接两个分部 $T,B$，且每个分部内部的邻居集可按包含关系全排序。把 $T$ 按邻居集从大到小排序、$B$ 从小到大排序，等值任意确定顺序。若有孤立点，它们都作为单点路径单独处理。链图最多有一个有边的连通分支，否则不同分支各取一条边会构成诱导 $2K_2$。

原论文借助正规形，在定长顶点表上枚举路径族及单点计数。划分的公布时间为 $O(n^7)$ [1, 引理 13]。利用文献的复制归约可得覆盖时间 $O(n^9)$ [1, 引理 14]。文献第 6 节明确提出改进这两个算法。

**定理.** 给定 $n$ 顶点链图，等距路径划分可在 $O(n^5)$ 时间求出，等距路径覆盖可在 $O(n^7)$ 时间求出。两者均返回最优的路径集合。

## 2. 正规形的槽位与配对

沿用 [1, 定理 6] 对正规形的分类。记 A 为有一个上顶点、两个下顶点的三点路径，V 为有两个上顶点、一个下顶点的三点路径，N 为上下各两点的四点路径。每条 N 的两个上顶点中，较强者邻接两个下顶点，较弱者只邻接较强的下顶点。这是因为邻居包含，且端点必须不邻接。对每个分部，用较强和较弱分别表示邻居集较大和较小的角色。

把 A 与 V 各分成在全部 N 外的族与在全部 N 内的族。正规形规定 A 在 V 的左侧，外部 A 位于 N 之前，外部 V 位于 N 之后。单点路径位于下侧最左和上侧最右。由 [1, 定理 6、图 1] 的分部顺序，含 N 的情形可写为下表。每行从左到右是该分部的连续槽位。

| 分部 | 槽位依次排列 |
|---|---|
| $T$ | 外部 A · N 较强点 · 内部 A · 内部 V · N 较弱点 · 外部 V · 单点 |
| $B$ | 单点 · 外部 A · N 较弱点 · 内部 A · 内部 V · N 较强点 · 外部 V |

没有 N 时，只需考虑 A 后接 V，并允许在二者之间有一条单边路径。相同三点路径族中的路径互不交叉，所以它们逐个消耗所在槽位，A 每次占一个上点、两个下点，V 每次占两个上点、一个下点。

对 N 的四个槽位块，每块大小等于 N 的数量。可以把四个块各自按原顺序排列，取同编号的四个点成一条路径。理由如下。任一符合槽位分布的 N 划分给出了两组边的完美匹配：上强到下弱、上弱到下强；还给出了上弱到下弱的非边完美匹配。取其中任一对同大小的槽位块，仍以上侧从强到弱、下侧从弱到强排序。

- 若要求边的匹配且第 $i$ 对同编号点不邻接，那么从第 $i$ 个开始的所有上点都不邻接前 $i$ 个下点。后缀上点数大于可用的下点数，违背完美匹配。
- 若要求非边的匹配且第 $i$ 对同编号点相邻，那么前 $i$ 个上点都邻接从第 $i$ 个开始的全部下点。前缀上点数大于可用的下点数，同样矛盾。

因此三种同编号配对均满足要求。上强到下强的边由包含关系自动得到。这就给出了重新拼接的 N 路径，且覆盖原有的四块顶点。

## 3. 常数时间检查一个正规形

只枚举外部 A、内部 A、N、内部 V、外部 V 的五个计数。若 N 为零，把两个 A 或两个 V 的计数合并，并可另取一个二元参数表示是否有中间的单边路径。每个分部需要的非单点槽位数由这些计数决定。若超过分部大小则舍弃，否则单点数也随之确定，无须猜测。所用路径数可从计数直接求得。

先把邻接关系存入以这两个分部顺序编号的矩阵。对于步长 $(1,2),(2,1),(1,1)$，分别预处理从每个矩阵位置开始沿对应方向连续出现边的最长长度。对于 $(1,1)$ 还预处理连续非边的最长长度。每张表可从右下向左上填写：当前位置符号若符合要求，值为一加下一个步长位置的值，否则为零。边界外值为零，所以四张表均在 $O(n^2)$ 时间构造。

A 只需检查其中心与较弱下点之间的边，该边在同族路径中以 $(1,2)$ 前进。V 对称地检查中心与较弱上点，步长 $(2,1)$。N 需检查两组边和一组非边，均为步长 $(1,1)$。各序列的起始位置由槽位计数决定。用预处理表检查一个族只需比较其计数与相应的连续长度。满足这些检验即可逐槽位构成一个等距路径划分。反过来，[1, 定理 6] 保证最优正规形存在，第二节的排序拼接使它通过检验。

总共有 $O(n^5)$ 个计数组合，每个耗时常数。由最优计数可在 $O(n)$ 时间恢复路径。排序和邻接矩阵预处理不超过此界。

## 4. 覆盖

文献 [1, 引理 14] 保证存在一个最优覆盖，只有两个最大邻域的分部顶点可能在多条路径中出现。猜这两个顶点各出现多少次，每个次数至多为 $n$。以具有相同跨分部邻接的副本代替多次出现的原顶点，得到仍为链图的实例。副本之间的跨分部邻接也按原顶点是否相邻决定。每个猜测产生 $O(n)$ 顶点，并可运行第三节的划分算法。

最优覆盖用正确的次数归约为同大小的划分，因为每次出现可以给不同副本。反过来，把最优划分的副本还原可得覆盖。若一条三点路径的两个端点还原为同一点，改为所余的单边路径即可。四点等距路径不能含同一原顶点的两个副本，因为它们会使端点间出现短边。对于还原后顶点仍互异的路径，路径邻接及端点的相邻性保持。长度至多三且两分部奇偶性固定，因此仍为最短路径。取所有 $O(n^2)$ 个猜测中最优者，耗时 $O(n^7)$。

## Rational exceptional biases at order eight

The supplement proves rationality for all exceptional biases at order eight. Its proof uses analytic bounds followed by a finite, exact computation.

- [Supplement](supplement.rational-biases.md) · [HTML reading copy](supplement.rational-biases.html)

Run the following from the project directory. The text files supply the shell script and the checksum manifest as printed.

```sh
cd code/rational-bias
cp reproduce.txt reproduce.sh
cp SHA256SUMS.txt SHA256SUMS
sh reproduce.sh
```

# Reproduction

## Reproducing the additional results

Use Python 3 with SciPy and mpmath. Run from this project directory.

~~~sh
python code/check_games.py > results/check_games.json
~~~

The [recorded calculations](results/check_games.json) give independent finite examples of the new analytical results.

The [finite-population calculations](results/exact_checks_and_illustrations.json) cover the original results.

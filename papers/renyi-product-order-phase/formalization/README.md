# Lean formalization

This package includes 139 Lean source files for Rényi contraction of repeated symmetric channels: finite-channel reductions, product coefficients, local and central limit results, asymptotic regimes, optimizer limits and related arithmetic and analytic lemmas. The archived project records mappings for the mathematical proof obligations and a separate outstanding matching-source build and all-declaration axiom audit requirement. This package is not classified as a verified full-paper formalization.

Run `lake build` with the specified toolchain and pinned dependencies. No new build or axiom audit was performed during migration.

# Matrix discrepancy on two-dimensional subspaces and sharp variance-profile bounds

For independent finitely supported real scalars multiplying rank-one positive semidefinite matrices, the smallest universal discrepancy constant is two standard deviations. Every finite instance with positive variance admits a choice from the original supports with strictly smaller discrepancy.

The paper also gives a determinant comparison for overlapping two-dimensional subspaces, a rectangular rank-one selection bound for finite complex scalar laws, and exact worst-case bounds for prescribed row and column variance profiles.

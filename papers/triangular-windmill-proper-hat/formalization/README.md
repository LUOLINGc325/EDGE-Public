# Formal proof

The archived release reports a full local kernel and independent scope audit; a new public build has not been run.

The original Lean source and pinned dependencies are reproduced without changes. Run `lake build` in this directory. The accompanying manuscripts are the archived original versions. External peer review and new compilation are not claimed.

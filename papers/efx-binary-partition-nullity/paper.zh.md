# 两类拟阵零度家务的最坏近似 EFX 因子

*精确到首项常数的匹配上下界*

# 模型与结论

有 $n\ge2$ 名代理人与 $3n-1$ 件不可分家务。每件家务带一个 $n$ 位二元标签，标签可以重复。每位代理人把家务按对应位分为两类。一束家务中，每个出现的类别首件免费，其余每件的费用为一。于是，对代理人 $i$，
$$c_i(T)=|T|-\#\{\text{在 }T\text{ 中出现的第 }i\text{ 位取值}\}.$$
该费用是两个容量为一的类别所定义的分割拟阵的零度。每加一件的费用为零或一，边际费用随原束增大而非减。

完整分配 $A=(A_1,\ldots,A_n)$ 是 $\alpha$-EFX，若对每个不同的 $i,j$ 和每件 $e\in A_i$，
$$c_i(A_i\setminus\{e\})\le \alpha c_i(A_j),\qquad \alpha\ge1.$$
也就是说，代理人从自己收到的家务中删去哪一件都可以，剩余费用至多是换成别人那束家务的 $\alpha$ 倍。比较对象费用为零时，左侧也必须为零。

令 $F_n$ 为这个模型中，所有实例的最优因子之最大值。本文给出
$$F_n\sim\frac{n}{\log_2 n}\quad(n\to\infty).$$
更具体地，对每个 $n\ge2$，
$$F_n\le\left\lceil\frac{n-1}{\lfloor\log_2 n\rfloor}\right\rceil,$$
而对充分大的 $n$，
$$F_n\ge\frac{n-1}{\lceil\log_2 n\rceil+5}-1.$$
因此即使直接在所有完整分配中优化，任何固定因子也会在足够大的实例上失效。上下界还给出一个由标签投影决定的逐实例判据。

Lin、Liu、Tao 与 Zhou 在相同的费用模型中，用 18 人和 53 件家务证明精确 EFX 可能不存在。本文保留他们的标签与匹配归约，分析最优近似因子随人数增长的速度。Barman、Narayan 与 Verma 的二元超模费用下界要求同时满足 Pareto 最优性。Christoforidis 与 Santorinaios 的无界下界采用更一般的超可加费用。 [Lin 等，定理 2](https://arxiv.org/abs/2608.10572v1) [Barman 等](https://arxiv.org/abs/2302.11530) [Christoforidis 与 Santorinaios](https://arxiv.org/abs/2406.10752)

# 由分配得到配对

称尺寸至少三的束为大束，其持有者集合为 $S$，大小为 $s$。因为总家务数超过 $2n$，至少存在一个大束。任何大束都有两件家务在持有者的坐标上相同。因此可以移除其中另一件，剩下正费用。这一比较表明，每个其他束必须至少有两件家务。又因总数小于 $3n$，至少有一个两件束。故 $1\le s\le n-1$，恰有 $r=n-s$ 个两件束。

在每个 $i\in S$ 看来，每个两件束必须有正费用。这等价于两件家务在第 $i$ 位相同。因此两件束由 $r$ 个不交叠的对构成，每对在 $S$ 上的投影一致。

对尺寸为 $b\ge3$ 的大束，删掉任一件后费用至少为 $b-3$，而任一两件束在该代理人看来费用恰为一。于是 $b-3\le\alpha$。相对每人两件的基准，总共有 $n-1$ 件超额家务，全部分给了大束。因此
$$n-1\le s(\alpha+1).$$

# 由配对构造分配

反过来，给定 $1\le s=|S|\le n-1$，若存在 $n-s$ 个在 $S$ 上投影相同的不交叠对，就给每位 $S$ 外的代理人分一对，再把余下 $2s+n-1$ 件家务均匀分给 $S$。每个大束的尺寸介于三与 $2+\lceil(n-1)/s\rceil$ 之间。

两件束的持有者移除一件后费用为零。大束持有者看每个两件束的费用恰为一，看任何大束的费用至少为一。大束移除一件后至少还占一个类别，费用至多为尺寸减二。故此构造达到 $\lceil(n-1)/s\rceil$-EFX。

投影标签为 $v$ 的类别若含 $f_v$ 件家务，可以独立贡献 $\lfloor f_v/2\rfloor$ 对。令 $s_*$ 为满足
$$\sum_v\lfloor f_v/2\rfloor\ge n-|S|$$
的集合 $S$ 的最大大小。由上述双向归约，任意实例的最优因子 $\alpha_*$ 满足
$$\max\left\{1,\left\lceil\frac{n-1}{s_*}\right\rceil-1\right\}
\le\alpha_*\le\left\lceil\frac{n-1}{s_*}\right\rceil.$$
这里可取整是因为每个大束持有者都以一束价值恰为一的两件束作最严格的比较，左侧费用均为整数。因此固定有限因子分配的最小因子为整数，有限个分配中的最优因子也是整数。

# 通用上界

任选 $k=\lfloor\log_2 n\rfloor$ 个坐标作为 $S$。投影最多有 $2^k\le n$ 个类别，逐类配对只会留下至多 $n$ 件未配家务。因此有至少 $(3n-1-n)/2=n-1/2$ 个对，足以选出 $n-k$ 对。上一节的构造给出所述上界。整个构造只需按投影标签分组、配对，然后均分余下家务。

# 随机标签的下界

现在独立均匀地为每件家务选取 $n$ 位标签。令 $t=\lceil\log_2 n\rceil+6$。证明当 $n$ 趋于无穷时，以趋近一的概率，不存在可供配对的集合 $S$ 满足 $s=|S|\ge t$。

先考虑 $r=n-s\le n/2$。至多有 $n^r$ 种选择补集，且至多有 $(3n-1)^{2r}\le(9n^2)^r$ 种选择 $r$ 个不交叠对。每份指定证据的概率为 $2^{-sr}$，因为每对的两件家务在每个指定坐标上以概率 $1/2$ 相同，并且各对不交叠。故对所有这类 $r$ 求和，概率至多
$$\sum_{r=1}^{\lfloor n/2\rfloor}\bigl(9n^3 2^{-n/2}\bigr)^r=o(1).$$

再考虑 $r>n/2$。若有一份证据，可以从中取出 $h=\lfloor n/2\rfloor$ 个不交叠对和 $t$ 个坐标。用 $m=3n-1$ 表示家务数，不交叠的 $h$ 对有至多 $m^{2h}/(2^h h!)$ 种选择。用 $h!\ge(h/e)^h$、$h\ge n/3$、$2^t\ge64n$，这类证据的期望数至多
$$\binom nt\left(\frac{e m^2}{2h\,2^t}\right)^h
\le n^t\left(\frac{27e}{128}\right)^h=o(1).$$
这里 $t=O(\log n)$，而 $27e/128<1$。若 $t>n$ 则根本没有这类坐标集合。对充分大的 $n$，两类证据的总概率小于一。于是存在一个实例满足 $s_*\le t-1$，而第一节的超额家务计数给出
$$\alpha_*\ge\frac{n-1}{t-1}-1.$$
上下界相除趋于一，且二者都与 $n/\log_2 n$ 渐近相等。

# 任意家务数量

若允许家务数量 $m$ 任意变化，仍有相同的最坏首项。若 $m\le2n$，让每人至多分到两件，其中任删一件后费用为零，所以能达到精确 EFX。若 $m\ge3n$，均分使束大小为 $q$ 或 $q+1$，其中 $q=\lfloor m/n\rfloor\ge3$。删去一件后的费用至多为 $q-1$，而另束的费用至少为 $q-2$，所以因子不超过二。若 $n$ 整除 $m$，各束大小相同，因子为一。

剩余情况写成 $m=2n+d$，其中 $1\le d\le n-1$。设 $s=\lfloor\log_2(d+1)\rfloor$，任选 $s$ 个坐标。因为 $2^s\le d+1$，最多剩下 $d+1$ 件无法在投影类别中配对的家务。至少可得到 $(2n+d-2^s)/2\ge n-1/2$ 个对。给 $n-s$ 位代理人各一对，再把余下 $2s+d$ 件均分给这 $s$ 位代理人。由于 $s\le d$，各大束至少有三件。与前文相同，构造的因子不超过 $\lceil d/s\rceil$。

当 $d\le n/(\log_2 n)^2$ 时，该因子至多为 $d$，可忽略于 $n/\log_2 n$。其余情况有 $s\ge\log_2 n-2\log_2\log_2 n-1$，统一上界为 $(1+o(1))n/\log_2 n$。取 $m=3n-1$ 提供匹配下界。因此允许任意件数也不改变最坏因子的首项和常数。

# 有限实例

遍历 Lin 等人原例的坐标子集得到 $s_*=8$。因而最优因子至少为 $\lceil 17/8\rceil-1=2$。一份可直接检查的分配达到二，所以原例的最优因子恰为二。该证书给出了全部分束，复现程序逐件删除并在原费用上检查每个比较。

用精确整数替换下界证明中的计数放缩，有限并合界在 $n=128$ 时给出 $14\le F_{128}\le19$，在 $n=512$ 时给出 $46\le F_{512}\le57$。

# 范围与复现

结论针对两类、单位容量的标签模型。逐实例投影判据针对 $3n-1$ 件家务。任意件数下的最差近似界也意味着，更一般的二元超模费用类不存在统一的常数保证。这里的下界为存在性结论。逐实例投影判据、有限算术证书及其形式化范围见复现说明。

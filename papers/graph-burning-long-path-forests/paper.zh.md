# 长路径森林燃烧阈值的构造性近线性上界

*用奇数配对实现精确长度分拆*

# 问题与结论

离散图燃烧从全图未燃开始。每轮选择一个未燃顶点点燃，先前火源同时沿图边继续传播。经过 $m$ 轮，第 $t$ 轮选的火源至多覆盖半径 $m-t$ 的球。路径中的这类球最多覆盖 $2(m-t)+1$ 个顶点。因而含 $N$ 个顶点的路径森林至少需要 $\lceil\sqrt N\rceil$ 轮。

设 $L_n$ 为最小阈值，使得所有由 $n$ 条路径构成且每条路径至少有 $L_n$ 个顶点的森林都达到上述下界。Tan 与 Teh 证明 $L_n$ 有限，又证明其至少为 $(12-o(1))n$，并猜想所有 $n\ge2$ 都有 $L_n\le12n$。本文给出显式的构造性上界
$$L_n\le 4096n(\lceil\log_2 n\rceil+8)^2,qquad n\ge2.$$
因此 $L_n=O(n\log^2 n)$。结合已知线性下界，得到 $\log L_n/\log n\to1$。线性上界猜想仍开放。 [存在性原文](https://arxiv.org/abs/2207.13855) · [阈值下界与猜想 3.1](https://arxiv.org/abs/2312.10914v3)

# 化为奇数分拆

先考虑顶点数恰为 $m^2$ 的森林。只要把奇数 $1,3,\ldots,2m-1$ 分配给各条路径，且每条路径得到的奇数之和恰为该路径长度，就可将路径按这些长度切成连续片段。用数值 $2r+1$ 对应的片段中心在第 $m-r$ 轮点火，第 $m$ 轮恰可烧完该片段。不同片段的中心距离至少为它们半径之和加一，因此每个中心按计划点火时仍未燃。

记 $b=\lceil\log_2 n\rceil+8$、$L=4096nb^2$。若最长路径减去 $2m-1$ 后仍不少于 $L$，就预先从其末端切下这段并留给相应奇数，随后将 $m$ 减一。总长度仍为平方。反复进行后，剩余总长度 $m^2$ 满足
$$64nb\le m<64nb+2n\le66nb.$$
下界来自总长至少 $nL$。上界来自最长路径小于 $L+2m-1$，所以 $m^2<nL+2nm$。求解这一二次不等式即得上界。以下只需处理这个缩小后的问题。已切下的片段最后接回即可。

# 为每个分界预留奇数

将奇数 $2a-1$ 用索引 $a\in\{1,\ldots,m\}$ 表示。令 $k=\lfloor\log_2 m\rfloor$。由 $m\le66nb$ 和 $n\le2^{b-8}$ 得 $k\le2b$。

对相邻路径 $i$ 和 $i+1$ 之间的分界 $i=1,\ldots,n-1$，预留一个单独奇数 $h_i=2i-1$。再预留三组索引对，每组包含 $k$ 对；各对形如 $(a,a+d)$，组内的 $d$ 依次取 $1,2,4,\ldots,2^{k-1}$。全部预留索引互异。现说明一定能选到。

最多需要 $Q=(n-1)(6k+1)\le13nb$ 个索引。设候选起点范围为 $1,\ldots,C$，其中 $C=2Q+1\le27nb$。已用索引至多使 $2Q$ 个起点不可用，因为每个已用索引只能作为候选对的起点或终点。故每次都能选到可用的 $a$。另外 $m\ge4Q+2$，且 $d\le m/2$，故 $a+d\le m$。所有预留物品都可以通过有限扫描构造。

单个分界预留的奇数总和不超过
$$2n+12kC+6m\le1046nb^2.$$
其中每对的两个奇数之和至多为 $4C+2d$，求和即得上式。每条路径只接触至多两个相邻分界。因此即使预先从两个分界各获得所有预留量，也仍小于目标长度 $L$。

# 用预留分界精确补齐前缀

先把同对中的较小奇数作为左侧的基准。换取较大奇数会向左多给 $2d$。一组二进制差值可表示从 $0$ 到 $2^k-1$ 的任意整数，三组可表示从 $0$ 到 $D_0=3(2^k-1)$ 的任意整数。故可向左增加从 $0$ 到 $2D_0$ 的任意偶数。额外的奇数 $h_i$ 可以分给左侧或右侧，从而还可增加 $h_i$ 加上这些偶数。由 $D_0\ge3(m-1)/2\ge m+n-2$，所有位于
$$[h_i-1,\ h_i-1+2m-2]$$
内的整数增量都可达到。该分界的初始分配取增量 $h_i-1$。

从各路径的目标长度扣去初始预留分配。每个剩余目标为正，且总和恰为自由奇数之和。按任意固定顺序列出自由奇数。对每个累计剩余目标，取总和不超过该目标的最长自由前缀。各切点非减。前缀短缺 $\delta_i$ 介于 $0$ 和 $2m-2$，因为下一个自由奇数至多为 $2m-1$。在分界 $i$ 上，把给左侧的预留量再增加 $\delta_i$，向右相应减少。它只改变第 $i$ 个累计和，对其他累计和没有影响。所有前缀同时补齐，每条路径遂得到所需的精确长度。预留、切分及解码均为确定性多项式时间操作。

# 非平方总长度

若 $N$ 不是平方，设 $m=\lceil\sqrt N\rceil$，暂时把一条路径延长到总顶点数为 $m^2$。对延长后的森林使用上面的构造。将落在新增段的火源移回最近的原路径端点，到任何原顶点的距离只会缩短，因此相同计划半径的球仍覆盖原森林。

如果投影后的某个计划火源在预定轮次已经燃烧，就改选任意未燃顶点。若已全部燃烧，则提前结束。更早的火源既已烧到计划位置，它在最终轮也能覆盖原计划火源应覆盖的全部顶点。因此这种替换保持完整覆盖。结合下界，燃烧数恰为 $m$。

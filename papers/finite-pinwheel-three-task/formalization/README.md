# Lean supplement for three-task pinwheel scheduling

For positive r, the r-th positive integer that is not divisible by 3 is r + floor((r - 1) / 2). For k at least 2, the rank formula gives three deadline inequalities used for the (2, 3, c) family.

From this directory, run `lake build` with the pinned Lean toolchain. The [verification summary](verification.json) records the checked declarations and their axiom dependencies.

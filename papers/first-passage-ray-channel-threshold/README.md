# Blind first-count calibration with singular quantum jump maps

**含奇异跳跃映射的量子首计数盲校准**

For a d-dimensional system with a positive definite total counting rate, the paper uses d² distinct positive frequencies to classify all models compatible with the full first-count maps known up to separate positive scales. The classification includes rank-one jump maps and the scalar-rate branch where the normalized response is constant.

对总计数率矩阵正定的 d 维系统，论文用 d² 个不同正频率下的完整首计数映射恢复物理参数。每个频率上的映射仅知到一个正比例因子。分类涵盖秩一跳跃映射，也给出归一化响应恒定时无法确定的自由度。
